# Telegram Shop Bot

## Запуск
1. Python 3.12+
2. `python -m venv .venv`
3. Linux/macOS: `source .venv/bin/activate`
   Windows: `.venv\Scripts\activate`
4. `pip install -r requirements.txt`
5. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN` и `ADMIN_ID`.
6. `python bot.py`

База `shop.db` создаётся автоматически.

## Важно про платежи
Кнопки Crypto Bot / ЮKassa / другие провайдеры заведены как управляемые методы оплаты, но для реального автоматического платежа нужны API-ключи, webhook и отдельная серверная точка. В этой версии полуавтоматический метод полностью реализован: пользователь создаёт заказ, получает реквизиты, отправляет подтверждение, владелец подтверждает/отклоняет, после подтверждения бот выдаёт свободный ключ.

## Безопасность
Не публикуйте `.env`, токен бота или ключи товаров в Git. Для production рекомендуется PostgreSQL, webhook через HTTPS, резервное копирование БД и журналирование платежей.
